# Diagram Sources

This directory contains version-controlled diagram source files.

- `diagrams/*.mmd` — Mermaid diagrams, rendered by Markdown viewers that support Mermaid.
- `diagrams/*.puml` — PlantUML/UML diagrams, rendered with a PlantUML-compatible toolchain.

Keep source diagrams aligned with `docs/02-architecture` and use the same terms as `docs/03-domain`.
